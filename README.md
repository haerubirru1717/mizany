# Mizany

Aplikasi web publik untuk mencatat amal harian — dipakai sepanjang tahun,
dengan mode khusus Ramadan. Selalu gratis, data di cloud, login Google,
tiap orang sendiri tanpa grup.

Amal default: puasa, sholat 5 waktu, tarawih, witir, tilawah, dzikir,
sedekah, sahur. Pengguna boleh menambah amal sendiri.
